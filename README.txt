【AI 研究助手(可拖动 · 可执行操作)】
    右下角 AI 悬浮按钮打开;按住标题行可拖动;标题行的锁形按钮在
    "可操作"与"仅分析"之间切换。结合当前页面数据问答,并可通过白名单工具
    替用户执行:修改策略表单参数、设置回测日期、保存并运行回测、运行样本复算、
    抓取行情、添加ETF、切换页面、查询运行详情;另有三项在服务端计算的工具:
    行情数据体检、回测深度诊断(回撤区间/成本/持仓)、Markdown 研究报告生成。
    保存、运行、抓取等会改动数据的操作先弹出确认卡片,用户确认后才执行。
    计算与解释分离:指标、异常、回撤区间与报告数字全部由 Java 业务层计算,
    AI 只解释结果。
    密钥保护:密钥仅存于服务端,优先级 application.yml > 环境变量
    ZHIPU_API_KEY > config/zhipu-key.txt;前端与页面源码中不出现密钥。
    *** 提交/打包作业前请删除 config/zhipu-key.txt(或换成空文件)***

【演示步骤】
    1. 概览页查看状态 → 回测运行页「运行样本复算」:12 项对照全部通过;
    2. 数据管理页「更新全部」+ 输入代码「添加并抓取」一只新 ETF;
       「检查数据质量」由服务端体检、AI 解释;
    3. 回测运行页选策略、区间 → 运行 → 结果页:顶栏的运行标识与导出、
       净值画板(策略实线/基准虚线,方向键可逐日查看)、指标对照;
    4. 交易记录页某笔成交行末「查看解释」→ 按"信号时间与触发条件 →
       因子排名与目标权重 → 次日实际执行"展示;
    5. 结果页顶栏「更多」→「零成本重跑」做附加对照,到运行历史页勾选两条
       →「对比所选」;顶栏「导出 ZIP」得七件套;
    6. 净值画板「AI 解读」:最大回撤分析、生成研究报告;
    7. 右下角 AI 助手:说"把动量窗口改成60并运行回测" → 确认卡片 → 执行。
